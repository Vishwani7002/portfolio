## ✨ Highlights

🌌 &nbsp; Interactive particle background that reacts to the cursor

⌨️ &nbsp; Typewriter intro with a flowing gradient headline

🃏 &nbsp; Project cards with 3D tilt and a spotlight hover

🎯 &nbsp; Filter projects by category

📊 &nbsp; Animated counters and scroll reveals

📄 &nbsp; One-click resume download and email copy
